Use this provider for a speech model served by any endpoint that implements the OpenAI speech API, such as a self-hosted server or a gateway.

## Required Fields

### Endpoint URL *

The base address of the server, usually ending in `/v1`, for example `https://speech.example.com/v1`. PipesHub appends the speech path to it.

### Model Name *

The model name the server expects, for example `tts-1`.

## Optional Fields

### API Key

The key the server expects. Leave it blank if the server does not check keys.

### Voice

The voice ID the server expects, typed as text, for example `alloy`. Leave it blank to use the server's default voice.

### Audio Format

The format of the returned audio: MP3 (default), Opus, AAC, FLAC, WAV or PCM. Choose one the server supports.

### Model Friendly Name

A label shown in the PipesHub interface so you can tell several configurations apart.

## Forward user identity

An OpenAI-compatible gateway can receive who is asking with each request. See [Identity forwarding](/ai-models/identity-forwarding).
