# Calculator

Arithmetic and date calculations. This toolset is **built in** — it needs no credentials and no external account.

Give an agent this toolset when it must produce exact numbers. Language models are unreliable at arithmetic, and a tool call is not.

## Available Tools

| Tool | What it does |
|------|--------------|
| `calculator.calculate_single_operand` | Single-operand math (square root, cube root) |
| `calculator.calculate_two_operands` | Two-operand math (add, subtract, multiply, divide, power) |
| `date_calculator.get_exclusion_dates` | Compute weekend and holiday exclusion dates for a range |
| `date_calculator.list_weekend_dates` | List all weekend dates in a date range |
| `date_calculator.parse_holiday_dates` | Extract holiday dates from raw text |

## Using it in an agent

1. Open **Agents** and create or edit an agent.
2. From the **Tools** panel, drag this toolset onto the canvas and connect it to the Agent Core.
3. To let the same agent also search indexed content, add a node from the **Knowledge** panel and connect that too.

The agent chooses which tool to call from the descriptions above, so a clear instruction such as "create an issue titled X" routes better than a vague one.
