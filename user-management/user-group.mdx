---
title: "User Groups"
description: "Where user groups stand in this edition"
---

User group management is not available in this edition. The **Groups** page in **Workspace Settings** shows an upgrade notice instead of group controls, so you cannot create, edit or delete groups here, and the Users page has no Groups column, group filter or group field on the invite panel.

To control who can do what, use these instead:

- **Roles.** Every user is an `Admin` or a `Member`. Change a role from the row actions menu on the [Users](/user-management/user) page.
- **Teams.** Any member can create a team and give each person on it the Owner, Writer or Reader role. See [Teams](/user-management/teams).
