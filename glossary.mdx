Terms are in alphabetical order. UI labels are in **bold**.

| Term | Meaning |
| --- | --- |
| **Actions** | Tools that agents use to work in other apps, such as sending an email or creating a ticket. Older pages call them toolsets. Admins set them up in **Workspace → Actions**; each person signs in to theirs in **Your actions**. See [Toolsets overview](/toolsets/overview). |
| Agent | An assistant you build in the visual agent builder from a model, knowledge, actions, skills and MCP servers. See [Agents](/agent-guide/overview). |
| Agent node | The central node of an agent in the builder. It holds the model, knowledge, tools, instructions and response settings. See [Agents](/agent-guide/overview#agent-node). |
| **AI models** | The language, embedding and other models PipesHub calls. Admins configure them in **Workspace → AI models**. See [AI models overview](/ai-models/overview). |
| **API actions** | Agent tools created from an OpenAPI spec, set up in **Workspace → Actions** or **Your actions**. Off by default; an admin turns on **Enable API actions** in **Workspace → Labs**. See [API actions](/agent-guide/api-actions). |
| **Artifacts** | Files that the assistant or an agent creates in a chat, such as a report, a chart or the output of code it ran. **All artifacts** lists them. See [Artifacts](/artifacts). |
| Citation | A numbered reference in an answer that points to the passage or web page it came from. See [Chat and search](/using-chat#read-an-answer). |
| **Collections** | Folders of files you upload yourself. **My collections** are yours; **Shared with me** are other people's that you can open. Agents and chat can search them. |
| Connector | A link to a source app, such as Google Drive or Slack, that syncs its content into PipesHub so it can be searched. Admins add workspace connectors in **Workspace → Connectors**; people add their own in **Your connectors**. See [Connectors overview](/connectors/overview). |
| Embedding model | The model that turns text into vectors for search. PipesHub needs one before it can index content. See [AI models overview](/ai-models/overview). |
| Indexing | The work PipesHub does after a file syncs or uploads: read it, split it, embed it and store it so search can find it. See [Indexing status](/indexing-status). |
| **Labs** | An admin page in **Workspace → Labs** with platform settings and features that are off or in beta by default, such as Projects, API actions and the trash. See [Getting around the app](/app-basics#labs-admins). |
| MCP (Model Context Protocol) | An open protocol for giving AI apps tools. PipesHub uses it two ways: it runs its own MCP server so other AI apps can search PipesHub ([MCP server overview](/mcp/overview)), and agents can use tools from outside **MCP servers** ([MCP servers in agents](/agent-guide/mcp-servers)). |
| Named entities | People, organizations and places that PipesHub finds in content during indexing. Off by default; an admin turns on **Extract Named Entities** in **Workspace → Labs** (under **Show advanced feature flags**). See [Indexing status](/indexing-status#data-extraction-with-ai). |
| OAuth 2.0 app | An app you register so that other software can call the PipesHub API on a user's behalf. See [OAuth 2.0 applications](/developer/oauth2). |
| Personal access token (PAT) | A token tied to your account for scripts and AI tools that call the PipesHub API or MCP server. See [Personal access tokens](/developer/personal-access-tokens). |
| **Projects** | A place for related work. It holds instructions, files, connectors and tools, and every chat started in it uses them. You can share it with people and teams. Off by default; an admin turns on **Enable Projects** in **Workspace → Labs**. See [Projects](/projects). |
| **Prompts** | The admin page in **Workspace → Prompts** where you set a custom system prompt for chats with the assistant. See [Chat and search](/using-chat#admin-settings-that-affect-chat). |
| Record | One item that PipesHub has synced or uploaded, such as a file, email, page or ticket. **All records** lists the ones you can see. |
| **Recently deleted** | The trash of a collection, where deleted files and folders wait before they are removed for good. See [Trash and Recently deleted](/trash). |
| Service account | An identity that a script or integration uses to call PipesHub with its own permissions, instead of a person's account. Admins create them in **Workspace → Service accounts**. |
| Service agent | An agent shared with the whole organization that uses agent-level credentials for its actions. See [Agents](/agent-guide/overview#service-agents). |
| **Skills** | Reusable instructions that an agent can load when a task calls for them. In beta. See [Skills](/agent-guide/skills). |
| **Teams** | Groups of workspace members who share resources. Each member is an Owner, Writer or Reader of the team. See [Teams](/user-management/teams). |
| User agent | A personal agent where each person signs in to the actions themselves. See [Agents](/agent-guide/overview#service-agents). |
| **Web search** | Lets chat and agents search the web and read pages. See [Web Search](/web-search). |
| **Workspace** | The settings area of PipesHub. Admins see workspace-wide settings; everyone sees their personal settings. |
