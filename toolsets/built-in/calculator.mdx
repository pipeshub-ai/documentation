# Calculator

Arithmetic and date calculations. This toolset is **internal** — no credentials, no external account, and it is attached to every agent automatically.

Give an agent this toolset when it must produce exact numbers. Language models are unreliable at arithmetic, and a tool call is not.

## Available Tools

| Tool | What it does |
|------|--------------|
| `calculator.calculate_single_operand` | Single-operand math (square root, cube root) |
| `calculator.calculate_two_operands` | Two-operand math (add, subtract, multiply, divide, power) |
| `date_calculator.get_exclusion_dates` | Compute weekend and holiday exclusion dates for a range |
| `date_calculator.list_weekend_dates` | List all weekend dates in a date range |
| `date_calculator.parse_holiday_dates` | Extract holiday dates from raw text |

## Using it in an agent

Nothing to add. This toolset is marked internal, so it is attached to every agent
automatically and its tools are always callable.

It does **not** appear under **Workspace settings → Actions**, and you will not find
it in the **Tools** panel of the agent builder — internal toolsets are held
server-side and are never sent to the interface. Do not go looking for it there.

The agent chooses when to call these tools from the descriptions above, so a
specific instruction routes better than a vague one.
