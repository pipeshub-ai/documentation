# Knowledge Hub

Searches indexed items in the Knowledge Hub by name, for when an agent needs to find a specific file rather than answer from its contents.

This toolset is **built in**. It needs no credentials and no external account, and it is loaded for every deployment.

## Available Tools

| Tool | What it does |
|------|--------------|
| `knowledgehub.list_files` | Search indexed items in the Knowledge Hub by name |

## Using it in an agent

1. Open **Agents** and create or edit an agent.
2. From the **Tools** panel, drag this toolset onto the canvas and connect it to the Agent Core.
3. To let the same agent also search indexed content, add a node from the **Knowledge** panel and connect that too.

The agent chooses which tool to call from the descriptions above, so a specific instruction routes better than a vague one.
