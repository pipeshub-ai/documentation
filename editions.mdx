PipesHub comes in three editions. Every page in these docs describes the open-source edition unless it says a feature is in the Enterprise edition.

## What the Enterprise edition adds

### Sign-in and user provisioning

- **SAML single sign-on** and **generic OAuth / OIDC sign-in** with your identity provider. See [Authentication](/auth).
- **LDAP / Active Directory sign-in**, with group membership synced from the directory.
- **SCIM provisioning**: create, update and deactivate people and groups from your identity provider.
- **Directory sync and just-in-time provisioning**: people and groups come from your directory, and a person's account is created at first sign-in.

### Governance

- **Organization-wide tool approval rules.** Admins set, for each tool in a toolset added for the organization, whether it runs, asks for approval or is denied. In the open-source edition these toolsets use fixed defaults. See [Governing agents](/agent-guide/governance).
- **Admin control of MCP server access**: choose which MCP servers people and agents in the organization may use.
- **Group-based permissions** for managing who can administer and use each part of the workspace.
- **Usage and spend limits** for model usage, by person and across the organization.
- **Branding**: your name and logo in the app.

### Scale

- **Connector sync across several workers**, with a shared lease so two workers never sync the same connector at once. In the open-source edition connector sync runs as one worker per pod. See [Reference architecture](/deployment/reference-architecture).

### AI and data

- **Automatic model selection**: each request goes to a model suited to it, with escalation to a stronger model when needed.
- **Entity resolution**: the same person, customer or project recognized across sources.
- **Answers over structured data**: questions answered from tables and databases alongside documents.

## Choosing an edition

- Start with **open source** to evaluate on your own data, or when password, Google or Microsoft sign-in is enough.
- Use **PipesHub Cloud** to try PipesHub without running servers.
- Choose **Enterprise** when you need SAML, OIDC, LDAP or SCIM, organization-wide agent approval rules, or connector sync across several workers.
