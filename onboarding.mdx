The first time an admin signs in, setup has three steps: an AI model, an embedding model and storage. The AI model and embedding model steps must be completed. Storage is optional and defaults to local storage. Email (SMTP), connectors and the rest are configured afterwards in **Workspace Settings**.

## Step 1: Configure AI Model (Required)

Before proceeding with the setup, configuring an AI model is mandatory. **Enter PipesHub** stays disabled until this step is saved.

1. Select the AI provider.
2. Provide the fields the provider asks for (for example the API key and the model name).
3. Save the model, then click **Next**.

### For more info, refer to [AI models Configuration Guide](/ai-models/overview).

<Info>AI model configuration is required to enable AI-powered features.</Info>

## Step 2: Configure Embeddings Model (Required)

The Embeddings Configuration section is part of the System Setup workflow for
enabling semantic search and document retrieval features in your application.
This configuration step allows you to define the embedding provider and
specify the model used for generating vector representations of textual
content.

1. Select the embedding provider.
2. Provide the fields the provider asks for (for example the endpoint, API key and model name).
3. Save the model, then click **Next**.

<img
  src="/images/onboarding/embeddings-new.png"
  alt="Onboarding embedding model step with providers and Skip button"
  width="100%"
/>

<Info>Next stays disabled until an embedding model is saved. If your deployment offers a system-provided default, **Skip** opens its setup; press **Add model** there to save it. You can change the embedding model later in workspace settings.</Info>

## Step 3: Configure Storage (Optional)

Setting up storage allows the system to save and retrieve data efficiently.
By default, local storage (local machine) will be used to store the files.

1. Choose a Storage Provider (Local, AWS S3 or Azure Blob Storage).

2. Enter the corresponding configuration.

- Mount name and Base URL (both optional) for **Local Storage**.
- Access Key and Secret Key for authentication and bucket Name or storage container details for **Amazon S3**.
- Account name, container name,account key, protocol and endpoint suffix for **Azure Blob**.

Save the configuration, then continue.

<img
  src="/images/onboarding/storage-new.png"
  alt="Onboarding storage step with Local storage selected"
  width="100%"
/>

### For more info, refer to [Storage Service documentation](/system-overview/storage).

<Info>You can skip this step. By default Local storage will be chosen.</Info>

## After onboarding

Click **Enter PipesHub** to finish. Then, in **Workspace Settings**:

- Set up email (SMTP) under **Workspace** > **Mail**. See the [SMTP guide](/smtp).
- Add connectors under **Connectors**. See [Connectors](/connectors/overview).
