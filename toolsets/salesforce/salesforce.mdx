## Overview

The Salesforce action enables AI agents to interact with your Salesforce CRM — searching and creating records, running SOQL/SOSL queries, managing the sales pipeline, posting to Chatter, and more. It uses OAuth so agents act on behalf of the authenticated user via a Salesforce External Client App.

### Key Capabilities

- **SOQL & SOSL queries** - Run structured object queries or full-text searches across any Salesforce object
- **Account & Contact management** - Search, create, and update accounts and contacts
- **Lead & Opportunity management** - Manage your pipeline from lead creation through opportunity close
- **Case management** - Create and search support cases
- **Product catalog** - Search products, list price books, and add products to opportunities
- **Task management** - Create and track activities across any related record
- **Files** - Upload PipesHub files to Salesforce Files and link them to records
- **Chatter** - Read Chatter feeds and post comments or updates on any record
- **Generic record CRUD** - Get, create, and update any standard or custom Salesforce object
- **Object metadata** - Describe any object to discover its fields and picklist values

## Available Tools

Parameters marked `?` are optional.

### Query Tools

| Tool | Description | Parameters |
|------|-------------|------------|
| `soql_query` | Execute a SOQL query against any Salesforce object | `query` |
| `sosl_search` | Execute a full-text SOSL search across multiple objects | `search` |

### Generic Record Tools

| Tool | Description | Parameters |
|------|-------------|------------|
| `get_record` | Retrieve a Salesforce record by its ID | `sobject`, `record_id`, `fields?` |
| `create_record` | Create a new record for any standard or custom object | `sobject`, `data?` |
| `update_record` | Update fields on an existing record by ID | `sobject`, `record_id`, `data?` |
| `describe_object` | Get field metadata, picklist values, and relationships for an object | `sobject` |
| `list_recent_records` | List the most recently viewed records of a given object type | `sobject`, `limit?` |

### Account Tools

| Tool | Description | Parameters |
|------|-------------|------------|
| `search_accounts` | Search accounts by name and/or industry | `name?`, `industry?`, `limit?` |
| `create_account` | Create a new Account record | `name`, `industry?`, `phone?`, `website?`, `description?`, `billing_city?`, `billing_state?`, `billing_country?` |

### Contact Tools

| Tool | Description | Parameters |
|------|-------------|------------|
| `search_contacts` | Search contacts by name, email, or parent account | `name?`, `email?`, `account_id?`, `limit?` |
| `create_contact` | Create a new Contact record | `last_name`, `first_name?`, `email?`, `phone?`, `title?`, `account_id?`, `department?` |

### Lead Tools

| Tool | Description | Parameters |
|------|-------------|------------|
| `search_leads` | Search leads by name, company, or status | `name?`, `company?`, `status?`, `limit?` |
| `create_lead` | Create a new Lead record | `last_name`, `company`, `first_name?`, `email?`, `phone?`, `title?`, `status?`, `industry?` |

### Opportunity Tools

| Tool | Description | Parameters |
|------|-------------|------------|
| `search_opportunities` | Search opportunities by name, stage, or account | `name?`, `stage?`, `account_id?`, `limit?` |
| `create_opportunity` | Create a new Opportunity record | `name`, `stage_name`, `close_date`, `account_id?`, `amount?`, `description?`, `probability?`, `attachment_record_ids?` |

### Case Tools

| Tool | Description | Parameters |
|------|-------------|------------|
| `search_cases` | Search cases by subject, status, priority, or account | `subject?`, `status?`, `priority?`, `account_id?`, `limit?` |
| `create_case` | Create a new Case (support ticket) | `subject`, `status?`, `priority?`, `origin?`, `description?`, `account_id?`, `contact_id?`, `attachment_record_ids?` |

### Product & Pricebook Tools

| Tool | Description | Parameters |
|------|-------------|------------|
| `search_products` | Search the product catalog by name, code, or family | `name?`, `product_code?`, `family?`, `active_only?`, `limit?` |
| `create_product` | Add a new product to the Salesforce product catalog | `name`, `product_code?`, `description?`, `family?`, `is_active?`, `quantity_unit_of_measure?` |
| `list_pricebooks` | List available price books (Pricebook2) | `name?`, `active_only?`, `limit?` |
| `create_pricebook_entry` | List a product in a price book with a unit price | `product_id`, `pricebook_id`, `unit_price`, `is_active?` |
| `add_product_to_opportunity` | Add a product line item to an opportunity | `opportunity_id`, `pricebook_entry_id?`, `product_id?`, `pricebook_id?`, `quantity?`, `unit_price?`, `description?` |

### File Tools

| Tool | Description | Parameters |
|------|-------------|------------|
| `upload_file_to_salesforce` | Upload PipesHub records (chat attachments, artifacts, knowledge base files) as Salesforce Files, and optionally link them to a record | `attachment_record_ids`, `link_to_salesforce_id?` |
| `attach_file_to_record` | Link an existing Salesforce file to a record | `content_document_id`, `record_id`, `share_type?`, `visibility?` |

### Task Tools

| Tool | Description | Parameters |
|------|-------------|------------|
| `search_tasks` | Search tasks by subject, status, priority, owner, or related record | `subject?`, `status?`, `priority?`, `owner_id?`, `what_id?`, `who_id?`, `limit?` |
| `create_task` | Create a new Task activity | `subject`, `status?`, `priority?`, `activity_date?`, `description?`, `owner_id?`, `what_id?`, `who_id?` |

### Chatter Tools

| Tool | Description | Parameters |
|------|-------------|------------|
| `get_record_chatter` | Get the Chatter feed (posts, comments, activity) for any record | `record_id` |
| `post_chatter_comment` | Reply to an existing Chatter feed item | `feed_element_id`, `text`, `is_rich_text?` |
| `post_chatter_to_record` | Post a new top-level Chatter update on a record | `record_id`, `text`, `is_rich_text?` |

### User Tools

| Tool | Description | Parameters |
|------|-------------|------------|
| `get_current_user` | Get the currently authenticated Salesforce user's profile and org details | None |

### Step 1: Open Salesforce Setup

1. Log in to your Salesforce instance and click the **gear icon** (⚙️) in the top-right navigation bar.
2. Select **Setup** from the dropdown menu.

### Step 3: Fill in basic information

Fill in the **External Client App Manager** form:

1. **External Client App Name** — Enter a name, for example `PipesHub Salesforce actions`.
2. **API Name** — Auto-filled from the app name; leave as-is.
3. **Contact Email** — Enter your admin email address.

### Step 4: Enable OAuth and add scopes

Scroll down to the **API (Enable OAuth Settings)** section:

1. Check **Enable OAuth**.
2. **Callback URL** — Paste the **Redirect URI** shown in the PipesHub **Action configuration** dialog (go to **Workspace → Actions → Salesforce → Set up**). It will look like `https://your-pipeshub-domain/toolsets/oauth/callback/salesforce`.
3. Under **OAuth Scopes**, move the following from **Available** to **Selected**:

| Scope | Description |
|-------|-------------|
| `Manage user data via APIs (api)` | Full REST API access to Salesforce data |
| `Perform requests at any time (refresh_token, offline_access)` | Allows token refresh without re-authentication |
| `Access the identity URL service (id, profile, email, address, phone)` | Read user identity |

### Step 5: Configure flow enablement and security

Scroll down to the **Flow Enablement** and **Security** sections:

1. Under **Flow Enablement**, check **Enable Authorization Code and Credentials Flow**.
2. Under **Security**, ensure the following are checked:
   - **Require secret for Web Server Flow**
   - **Require secret for Refresh Token Flow**
   - **Require Proof Key for Code Exchange (PKCE) extension for Supported Authorization Flows**
3. Click **Save**.

1. After saving, click the **Consumer Key and Secret** button in the **OAuth Settings** panel.
2. On the **Consumer Details** page, copy:
   - **Consumer Key** → this is your **Client ID** in PipesHub.
   - **Consumer Secret** → this is your **Client Secret** in PipesHub.

### Step 7: Find your Salesforce Instance URL

Your **Instance URL** is your org's My Domain URL. In Setup, search for **My Domain** in the **Quick Find** box and copy the **Current My Domain URL**, for example `https://yourcompany.my.salesforce.com`. Don't use the `*.lightning.force.com` address from your browser's address bar, and don't use `https://login.salesforce.com`.

### Step 8: Configure the Salesforce action in PipesHub

1. In PipesHub, go to **Workspace → Actions**.
2. Find **Salesforce** and click **Set up**.
3. In the **Action configuration** dialog, fill in:
   - **Instance name** — A label for this connection (e.g., `Salesforce`).
   - **Salesforce Instance URL** — the URL from Step 7.
   - **Salesforce Login URL** (optional) — where you sign in. Leave it blank for a production org. For a sandbox, enter `https://test.salesforce.com` or the sandbox's My Domain address (for example `https://yourcompany--uat.sandbox.my.salesforce.com`), and use the sandbox's My Domain address as the Instance URL. Only `https://` addresses on `salesforce.com`, with nothing after the host name, are accepted. The [Salesforce connector page](/connectors/salesforce/salesforce#connect-a-salesforce-sandbox) has the full sandbox steps.
   - **Client ID** — the Consumer Key from Step 6.
   - **Client Secret** — the Consumer Secret from Step 6.
4. Confirm that the **Redirect URI** at the top of the dialog matches the Callback URL you entered in Salesforce Step 4.
5. Click **Create**.

### Step 9: Authenticate the action

1. In the sidebar, open **Your actions** under the **Personal** section.
2. Select your **Salesforce** instance — you will see all available actions listed.
3. Click **Authenticate with OAuth** in the dialog that appears.
4. A sign-in popup will open — log in to Salesforce and approve the requested permissions.

1. Go to the **Home** page and click **+** next to **Agents**.
2. Give the agent a name.
3. From the **Palette**, drag the **Salesforce** action block onto the canvas.
4. Connect it to the **Agent** node (along with your model, chat input, and chat output), then click **Create agent**.

## FAQ

<AccordionGroup>

<Accordion title="What's the difference between Salesforce Connector and Salesforce Action?">

| Aspect | Salesforce Connector | Salesforce Action |
|--------|----------------------|--------------------|
| **Purpose** | Sync and index Salesforce records for search | Enable agents to perform CRM actions |
| **Data Flow** | One-way (import data into PipesHub) | Two-way (read and write via API) |
| **Auth Type** | OAuth (`api`, `refresh_token`, `offline_access`); the connector only reads data | OAuth with API access (`api`, `refresh_token`, `id`) for reading and writing |
| **When to Use** | Query/search Salesforce records and history | Create records, update deals, post to Chatter |

</Accordion>
