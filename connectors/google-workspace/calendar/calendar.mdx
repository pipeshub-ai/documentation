<Note>
  There is no dedicated Google Calendar connector. Calendar access is available through the [Google Calendar toolset](/toolsets/google-workspace/calendar), which lets agents view, create, and manage events directly.
</Note>

## How to set it up

1. Head over to the [Google Calendar toolset](/toolsets/google-workspace/calendar) page.
2. Follow the setup guide to create a Google Cloud project, enable the Calendar API, and configure OAuth credentials.
3. Authenticate the toolset in PipesHub.

Once authenticated, your agents can view upcoming events, schedule new meetings, update or delete events, and generate Google Meet links.

## More about the toolset

For the full list of available tools, setup steps, and usage tips, see the [Google Calendar toolset](/toolsets/google-workspace/calendar) documentation.
