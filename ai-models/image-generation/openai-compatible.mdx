Use this provider for an image model served by any endpoint that implements the OpenAI images API, such as a self-hosted server or a gateway.

## Required Fields

### Endpoint URL *

The base address of the server, usually ending in `/v1`, for example `https://images.example.com/v1`. PipesHub appends the images path to it.

### Model Name *

The model name the server expects, for example `gpt-image-1`.

## Optional Fields

### API Key

The key the server expects. Leave it blank if the server does not check keys.

### Model Friendly Name

A label shown in the PipesHub interface so you can tell several configurations apart.

## Forward user identity

An OpenAI-compatible gateway can receive who is asking with each request. See [Identity forwarding](/ai-models/identity-forwarding).
