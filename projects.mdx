A project keeps related work in one place. It holds instructions, files, connectors and tools. Every chat you start in a project uses them.

<Note>
  Projects are off by default. An admin turns them on in **Workspace → Labs** with **Enable Projects**. Once on, **Projects** appears in the chat sidebar.
</Note>

## Create a project

1. In the chat sidebar, select **Projects**, then **New project**.
2. Enter a **Name**. **Description** and **Instructions** are optional.
3. Select **Create project**.

The project opens. Only you can see it until you share it.

## Set up a project

The project page shows a **Project setup** panel. Each part is optional.

| Part | What it does |
| --- | --- |
| **Instructions** | Instructions the assistant follows in every chat in this project. Select **Edit instructions** to change them. |
| **Files** | Select **Upload files** to add files. They are indexed and searched only within this project. |
| **Connectors** | Chats in this project search only the connectors you add here. |
| **Tools & MCP** | Chats in this project can use only the actions and MCP servers you tick here. Only actions and MCP servers you're signed in to are listed. |
| **Chat defaults** | The **Model** and **Reasoning effort** new chats in this project start with. |

A tool that can delete data shows **Needs approval**. In a project chat it runs only after someone approves it.

## Chat in a project

Open the project and type in the chat box, or pick a suggestion such as **Summarize a document**. Every chat you start there uses the project's instructions, files and tools.

In a project chat you can still change the sources and tools for that chat. Select **Reset to project defaults** to go back to the project's settings. See [Using chat](/using-chat) for the chat controls.

## Move a chat into a project

1. In the chat sidebar, open the menu of a chat you started.
2. Select **Move to project** and pick a project.

To take a chat out of a project, select **Move to project** and choose **No project**.

You can only move your own chats, and only into a project you can open. You can't move a chat into an archived project.

## Share a project

The owner shares a project:

1. Open the project and select **Share**.
2. Add people or teams, and give each a role:
   - **Can edit**: change the name, instructions, files, connectors and tools, and chat in the project.
   - **Can view**: open the project and chat with its files and tools.
3. Under **Who can find this project**, choose:
   - **Only people it's shared with**: only you and the people or teams you added can open it.
   - **Everyone in your organization**: anyone in your organization can find and open it, with view access.
4. Under **New chats in this project**, choose:
   - **Private to whoever starts them**: each chat stays private unless its author shares it.
   - **Shared with project members**: members can see new chats. An author can still make a chat private.

A member who no longer needs a project can select **Leave project**. Their chats stay theirs. If access comes from the organization or a team, they can't leave; the owner has to change who it's shared with.

## Pin, archive and delete

From the project's actions menu:

- **Pin** keeps the project at the top of your list, under **Pinned**.
- **Archive project** (owner only) moves it to the **Archived** tab. No one can start new chats in an archived project. Select **Unarchive project** to restore it.
- **Delete project** (owner only) can't be undone. Files uploaded to the project are deleted for good, and everyone it's shared with loses access. Chats are kept, but are no longer part of a project.

Editors can also use **Edit name and description**.
