# Artifact Manager

Saves and retrieves versioned artifacts an agent has composed, so output survives beyond a single reply.

This toolset is **internal**. It needs no credentials and no external account, and it is loaded for every deployment and attached to every agent.

## Available Tools

| Tool | What it does |
|------|--------------|
| `artifacts.get_artifact_download_url` | Get a short-lived, permission-checked download URL for an existing artifact |
| `artifacts.get_record_download_url` | Get a download URL for a record (uploaded file or connector record) |
| `artifacts.list_artifacts` | List every artifact generated so far in this conversation |
| `artifacts.promote_artifact` | Promote a staging artifact to visible, surfacing it to the user as a download card |
| `artifacts.save_artifact` | Save text/data content you composed as a new versioned artifact, or update an existing one with the same name |
| `artifacts.update_artifact` | Update an existing artifact (by artifact_id) with new content, creating a new version |

## Using it in an agent

Nothing to add. This toolset is marked internal, so it is attached to every agent
automatically and its tools are always callable.

It does **not** appear under **Workspace settings → Actions**, and you will not find
it in the **Tools** panel of the agent builder — internal toolsets are held
server-side and are never sent to the interface. Do not go looking for it there.

The agent chooses when to call these tools from the descriptions above, so a
specific instruction routes better than a vague one.
