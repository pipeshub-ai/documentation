Many apps have their own MCP server. Is it better for an agent to call each app directly, or to search one index of all of them? PipesHub tested it with the same agent and the same questions. The index won on accuracy, speed and cost for all three Claude models.

PipesHub ran this test itself. The full write-up is the blog post [Do AI agents need a company index? We tested it](https://pipeshub.com/blog/do-ai-agents-need-a-company-index) (October 2026). For how the two approaches differ, see [Connectors, MCP and Actions](/connectors-mcp-actions).

In plain words: the agent answered the same questions twice, once by calling each app one at a time and once by searching one index of all of them. "Facts found" is the share of the facts in the correct answer that the agent's answer contained.

## Setup

- **The agent.** The same Claude model (Haiku, Sonnet or Opus) with the same instructions in both setups. PipesHub's own chat assistant was turned off, so only the way the agent looked things up changed.
- **Each app directly.** The agent used each tool's official connector: Slack, Atlassian (Jira and Confluence) and GitHub.
- **The index.** The agent searched one PipesHub index covering Slack, Jira, GitHub, Confluence and Google Drive, then opened the records it found.
- **The data.** One company's own data: about 13,000 Slack messages, 3,800 Jira tickets, 2,400 GitHub pull requests, plus Confluence pages and Google Drive files.
- **The questions.** 100 everyday work questions, many needing two or three tools. Humans wrote each correct answer and a list of required facts. Two AI models graded every answer against that list and a third settled disagreements. The graders agreed on 95% of facts. Each setup ran every question twice.

## Results

| Model | Facts found: direct → index | Time per answer | Cost per answer |
|---|---|---|---|
| Haiku | 55% → 80% | 29 s → 19 s | $0.012 → $0.009 |
| Sonnet | 65% → 89% | 29 s → 22 s | $0.24 → $0.16 |
| Opus | 85% → 92% | 55 s → 40 s | $0.58 → $0.41 |

With the index, the agent also made fewer lookups (for Sonnet, 11.8 down to 7.8 per answer) and read about half as much text (192,000 down to 100,000 tokens).

## Where the index helped most

- **Questions that need several tools.** Sonnet scored 72% with direct access and 90% with the index.
- **Slack history.** Sonnet scored 41% with direct access and 89% with the index.
- **Smaller models gained most.** Haiku gained 25 points. Opus gained 8, so for the strongest model the case rests more on speed, cost and checkable sources.
- **Sonnet with the index beat Opus without it** (89% against 85%), at about a quarter of the cost and under half the time.

## Where it did not

- **Summaries over a long period** scored 80% in both setups for Opus.
- **"What changed" questions** scored 93% direct and 91% with the index.
- **An index is a copy.** For something that changed in the last few minutes, the live app is the source of truth.

## Caveats

- **One company, 100 private questions, five tools.** The questions cannot be published. Results may differ for larger organizations or less technical work.
- **AI graders with human-checked answer keys.** After an audit, 16 answer keys were fixed in a first round and 13 in a second, and both setups were regraded. The fixes moved the index's lead by no more than 2 points.
- **Official connectors change.** Results reflect the connectors available on 19 October 2026.
- **PipesHub builds the index it tested.** A later round is planned on public data with the questions, answer keys and test code published.
