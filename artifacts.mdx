An artifact is a file the assistant or an agent creates in a chat, for example a report, a chart, a spreadsheet, an image or the output of code it ran. Artifacts are kept with versions, so you can download them later.

## What creates an artifact

- Files that code run in chat writes.
- Images the agent generates.
- Content the agent writes and saves as a file, such as a Markdown report, a CSV table or JSON data. The built-in **Artifact Manager** action does this. It can also update an artifact, which creates a new version.

The answer shows the files it created, for example "2 artifacts generated". From there you can **Preview artifact**, **Download artifact**, or view the code that generated it. If a newer version exists, the chat says **Newer version available**.

## Find your artifacts

Select **All artifacts** in the chat sidebar. The page has three tabs:

- **All artifacts**: everything you can open.
- **Mine**: artifacts from your chats.
- **Shared with me**: artifacts other people shared with you.

Search by name, filter by **Type** (for example **Document**, **Spreadsheet**, **Image** or **Code**) or **Date created**, and switch between **Grid view** and **List view**. List view shows each artifact's type, the chat that created it, the date and the size.

## Work with an artifact

Open an artifact's menu to:

- **Preview** it.
- **Download** it.
- **Open in chat**, to go to the chat that created it. This shows only when you can open that chat.
- **Share** it (owner only).
- **Delete** it (owner only).

  <img src="/images/product/artifacts/artifact-preview.png" alt="Artifact preview panel showing a chart image with its version and a download button" />

## Who can see an artifact

An artifact belongs to the person whose chat created it. That includes chats with an agent, even a service agent.

The owner can share an artifact with people in the organization. They can view and download it. Only the owner can share or delete it. Sharing works with people only, not teams.

## Delete an artifact

1. Open the artifact's menu and select **Delete**.
2. Confirm in **Delete artifact?**.

The artifact and all its versions are deleted for good. Chats that showed it mark it as **No longer available**.

Deleting a chat also deletes the files the assistant created in it.
