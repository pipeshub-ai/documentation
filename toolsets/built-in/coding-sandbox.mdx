# Code Sandbox

Run Python or TypeScript in an isolated sandbox. This toolset is **built in** — it needs no credentials and no external account, so it is available to any agent straight away.

## Available Tools

| Tool | What it does |
|------|--------------|
| `coding_sandbox.execute_python` | Execute Python code in an isolated sandbox to generate files and artifacts |
| `coding_sandbox.execute_typescript` | Execute TypeScript code in an isolated sandbox to generate files and artifacts |

## Using it in an agent

1. Open **Agents** and create or edit an agent.
2. From the **Tools** panel, drag this toolset onto the canvas and connect it to the Agent Core.
3. To let the same agent also search indexed content, add a node from the **Knowledge** panel and connect that too.

The agent chooses which tool to call from the descriptions above, so a clear instruction such as "create an issue titled X" routes better than a vague one.
