<Note>
  Google Docs is not a standalone connector currently. Documents in Google Docs stored in Drive are synced through the [Google Drive](/connectors/google-workspace/drive/drive) connector. Use the **File Extensions** sync filter on the Drive "Configure Records" page to sync only documents.
</Note>

## How to sync Google Docs

1. You can set up the Google Drive connector by following this [guide](/connectors/google-workspace/drive/drive) (Enterprise or Individual).
2. Once the drive connector instance is authenticated go to its **Configure Records** page.
3. Under **Sync Filters**, add **File Extensions**.
<div style={{ textAlign: "center" }}>
  <img
    src="/images/connectors/googleWorkspace/common/sheet1.png"
    alt="Add File extension filter"
    style={{ display: 'block', margin: '0 auto' }}
    width="90%"
  />
</div>
4. Set the operator to **In**.
5. Select the following document types:
   - `Google Docs`
   - `docx`
   - `doc`
   - `odt`
   - `rtf`

<div style={{ textAlign: "center" }}>
  <img
    src="/images/connectors/googleWorkspace/common/docs2.png"
    alt="Add File extension filter"
    style={{ display: 'block', margin: '0 auto' }}
    width="90%"
  />
</div>

<Info>
  The "In" operator syncs only the extensions you select. If you leave **File Extensions** unset, Drive will sync every file type, including documents.
</Info>

## Supported document types

| Type | Filter value |
|------|----------------|
| Native Google Docs | `Google Docs` |
| Word | `docx`, `doc` |
