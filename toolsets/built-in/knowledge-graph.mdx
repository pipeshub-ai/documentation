# Knowledge Graph

Walks the knowledge graph structurally — App to RecordGroup to Record to children — for questions about how content is organised rather than what it says.

This toolset is **built in**. It needs no credentials and no external account, and it is loaded for every deployment.

## Available Tools

| Tool | What it does |
|------|--------------|
| `knowledgegraph.list_files` | Search or browse indexed items by name (returns metadata, not content) |
| `knowledgegraph.lookup_record` | Resolve a URL, issue key, or external ID to a Record ID |
| `knowledgegraph.navigate` | Browse the knowledge graph by node (App → RecordGroup → Record → children) |
| `knowledgegraph.search` | Semantic search over indexed knowledge (returns ranked content blocks) |

## Using it in an agent

1. Open **Agents** and create or edit an agent.
2. From the **Tools** panel, drag this toolset onto the canvas and connect it to the Agent Core.
3. To let the same agent also search indexed content, add a node from the **Knowledge** panel and connect that too.

The agent chooses which tool to call from the descriptions above, so a specific instruction routes better than a vague one.
